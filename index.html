入試直前に見直す要点ノート

細かい例外よりも、まず頻出の型をまとめています。

① 不定詞の代表的な用法

名詞的：To read is fun. / I want to read.

形容詞的：I have a lot of work to do.

副詞的：I went there to see her.（目的）

感情の原因：I’m glad to hear that.

判断の根拠：He must be a fool to say that.

結果：He grew up to be a doctor. / only to find ...（ところが〜と分かる）

② 不定詞の頻出構文

too ... to do（あまりに〜でできない）

... enough to do（〜するのに十分…）

so ... as to do（〜するほど…）／in order to do・so as to do（〜するために）

It is ... for A to do（Aが〜するのは…）

It is ... of A to do（Aが〜するとは…：人の性質・行為を評価）

疑問詞＋to do：what to do / how to use it

完了形：to have done（主節より前）／受動：to be done

③ 動名詞を取る主な語

enjoy, avoid, finish, mind, give up, admit, deny, consider, suggest, postpone, put off, practice, risk, escape, imagine, miss, keep (on), quit

前置詞の後ろは名詞相当：before leaving / without saying anything

be worth doing / have difficulty (in) doing / feel like doing / cannot help doing

④ to が前置詞になる表現

look forward to doing / be used to doing / get used to doing / object to doing / be opposed to doing / be committed to doing / with a view to doing

ここでの to は不定詞の to ではなく前置詞。後ろは名詞または動名詞。

⑤ doing と to do で意味が変わる

remember doing：したことを覚えている ／ remember to do：忘れずにする

stop doing：〜するのをやめる ／ stop to do：〜するために立ち止まる

try doing：試しに〜してみる ／ try to do：〜しようと努力する

mean doing：〜を意味する・結果として伴う ／ mean to do：〜するつもりだ

go on doing：続けて〜する ／ go on to do：次に〜する

regret doing：したことを後悔する ／ regret to say：残念ながら〜を伝える

⑥ 分詞の基本

現在分詞 doing：能動・進行のイメージ（a sleeping baby）

過去分詞 done：受動・完了のイメージ（a broken window）

物事が人に与える感情：interesting / boring ／ 人の感情：interested / bored

分詞は修飾する名詞との関係で判断する。a falling leaf（落ちている葉）／ a fallen leaf（落ちた葉）

⑦ 分詞構文

Walking along the street, I met Ken.（歩いているとき）

Having finished my homework, I went out.（宿題を終えてから）

Seen from the hill, the town looks beautiful.（丘から見ると）

Being tired, I went to bed early.（疲れていたので）

主節の主語と分詞構文の意味上の主語が一致するのが原則。受動は being/having been＋過去分詞も使う。

⑧ 使役・知覚動詞

make / let / have＋目的語＋動詞の原形（能動）

get＋目的語＋to do

see / hear / watch＋目的語＋原形：動作全体を知覚

see / hear / watch＋目的語＋doing：進行中の場面を知覚

受動の make：be made to do（to が戻る）
